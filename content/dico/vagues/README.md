# Vagues de production du Lexique IA

Chaque dossier garde la trace d'une vague d'écriture : le brief donné aux agents de contenu (`BRIEF.md`), les lots de fiches qu'ils ont rendus (`lot-*.js`) et, parfois, des enrichissements de fiches déjà publiées (`enrichissements.json`).

Ce sont des archives figées. Les fiches ont été fusionnées dans `lexique/terms.js`, qui reste la seule source de vérité et a souvent été retouché depuis. Les règles en vigueur sont dans `../brief-fiche.md`. Pour relire une vague avec les contrôles actuels : `node scripts/check-lot.mjs --archive content/dico/vagues/<dossier>/lot-*.js` (les règles ajoutées depuis y sortent en avertissements).
